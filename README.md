## ✨ Features

### 🎯 Splash Screen
- Animated **Domative** branded intro with gold accent design
- Random motivational quote on every launch
- Tagline: *"Dominate Your Every Day"*

### 📊 Daily Progress Ring
- Animated circular progress tracker
- Live percentage of tasks completed
- Colour-coded progress bar

### 💡 Daily Spark (Motivation Quotes)
- 10 built-in motivational quotes from great leaders
- Previous / Next navigation
- "New Quote" button for instant refresh

### ✅ Task Manager
- Add tasks with **High / Medium / Low** priority
- Tap any task to mark it as complete
- Progress ring updates in real time
- Clear completed tasks with one tap
- Enter key support for fast task entry

### ⏰ Reminders
- Pinned reminder cards with icons and times
- Dismiss any reminder with ✕

### 🔔 Smart Notifications
- Bell icon opens a full notification panel
- Toast pop-ups fire automatically for:
  - Task completions
  - 50% milestone alert
  - 100% completion celebration
  - Periodic motivational nudges (every 25 seconds)

### 📈 Stats Dashboard
- Completed tasks count
- Pending tasks count
- 🔥 Day streak tracker
- Live **Focus Score** (A+ → D) based on completion rate

## 🛠️ Getting Started

### Option 1 — Open locally
Just double-click `index.html` in any browser. No server needed.

### Option 2 — GitHub Pages
1. Fork or clone this repo
2. Go to **Settings → Pages**
3. Set source to `main` branch → `/ (root)`
4. Visit `https://yourusername.github.io/domative-app`

### Option 3 — Git CLI
```bash
git clone https://github.com/yourusername/domative-app.git
cd domative-app
open index.html
```

## 📱 Design Highlights

- **Dark navy + gold** colour palette — bold and motivating
- **Playfair Display** serif for headings — editorial and strong
- **DM Sans** for body — clean and modern
- Smooth CSS animations and micro-interactions
- Mobile-first, responsive layout (max-width 480px)
- Circular SVG progress ring with stroke-dashoffset animation
- Linear gradient header with curved bottom edge
